# RVocab

Название **RVocab** означает **R**ational **Vocab**ulary (*с англ.* — «рациональный словарный запас»).

Учите только те слова на английском, которые вам нужны.

## Как пользоваться
- Создайте файл *text.txt* рядом с *rvocab.exe*.
- Скопируйте необходимый текст на английском в файл *text.txt*.
- Запустите *rvocab.exe*.
- Появиться файл *rvocab.html* в котором будет список всех слов из текста, отсортированный по частоте. Каждое слово будет ссылкой на Яндекс Переводчик.
- Откройте файл *rvocab.html* в браузере.
